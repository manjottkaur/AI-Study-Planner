# 📚 AI Study Planner

AI Study Planner is a Machine Learning-based web application that predicts the recommended study hours for students based on their academic details.

## 🚀 Features

- Predicts recommended study hours
- User-friendly web interface
- Machine Learning using Random Forest Regressor
- Flask backend with HTML, CSS, and JavaScript frontend

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript

## ▶️ How to Run

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Run the application:

```bash
python app.py
```

3. Open your browser and visit:

```
http://127.0.0.1:5000
```
